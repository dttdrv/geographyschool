## 2024-05-24 - MapLibre Events Causing Unthrottled React Re-renders
**Learning:** High-frequency map events (`mousemove`, `move`) connected directly to React state updates (`onCoordinatesChange`, `onMeasure`) cause rapid unthrottled re-renders. This results in significant main-thread blocking, particularly detrimental on lower-end hardware (like Chromebooks, a primary target for this app). MapLibre rendering is fast, but linking those frames 1:1 with React component re-rendering is a major anti-pattern.
**Action:** Always decouple fast continuous map updates (like dragging a measurement line or moving the mouse pointer) from React state. Implement a throttle/debounce mechanism (e.g., via `useRef` to track `lastUpdate` and skip state dispatches) to limit React updates to a human-perceptible frame rate (e.g., 20fps or ~50ms intervals) while allowing the map engine to run at 60fps.
