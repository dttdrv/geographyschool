## 2024-03-13 - Path Traversal (Zip Slip) in Data Scripts
**Vulnerability:** The data processing scripts (`scripts/processFullBulgaria.cjs`, `scripts/processAllCountries.cjs`, `scripts/processGeoNames.cjs`) used `adm-zip`'s `extractAllTo(destDir, true)` to extract downloaded zip files directly to the filesystem. This function is vulnerable to Zip Slip, where a malicious zip archive containing file paths like `../../../../etc/passwd` could overwrite arbitrary files outside the intended destination directory.
**Learning:** Even internal data processing scripts must defensively handle external data, as compromised upstream sources or MITM attacks (despite HTTPS) could lead to remote code execution or file overwrite on the build/processing server. The `adm-zip` library does not automatically sanitize paths during bulk extraction.
**Prevention:** Avoid `extractAllTo()`. Instead, manually iterate through `zip.getEntries()` and resolve each `entryName` against the absolute `targetDir`. Use `path.resolve()` and explicitly verify that the resolved path starts with `targetDir + path.sep` before writing the file or creating directories.
